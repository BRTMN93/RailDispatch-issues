# RailDispatch: bug reports and ideas

This repository is the public issue tracker for **RailDispatch**, a Satisfactory mod that sends your trains to the stations that need cargo. The mod is on [ficsit.app](https://ficsit.app/mod/RailDispatch).

The mod's source code is not published here. This repository holds only issues.

## Reporting a bug

Open an issue and use the **Bug report** template. Please attach:

- `FactoryGame.log` from `%LOCALAPPDATA%\FactoryGame\Saved\Logs\`. Lines starting with `LogRailDispatch` are the most useful.
- Your game version, the mod version and your other mods (the SMM profile or a list).
- What you expected and what happened. Name the trains and stations involved.
- For a crash, the folder `%LOCALAPPDATA%\FactoryGame\Saved\Crashes\UECC-Windows-...` zipped.
- If you can share it, a save that shows the problem.

## Ideas

Use the **Idea** template. Please describe the situation in the game, not only the feature.
